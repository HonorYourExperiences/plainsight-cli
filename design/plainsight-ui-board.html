1 · Focus on select. The chosen part and its pipes stay sharp; everything else fades so the path reads at a glance.
2 · Checks live on the pipe. A valve means a login check guards this entrance. The red gap means one is missing.
3 · Problem first. Severity, one plain sentence, and the code behind it, before any description.
4 · Every sentence has receipts. Open a line to see the file and lines that prove it.
5 · Coverage is always visible. How much of the repo the drawing accounts for.
OPEN UX QUESTIONS
Labels get small when the whole app fits on screen. Big repos (200+ parts) need zoom levels: zones → groups → parts. The empty band above the drawing wastes space. Should "Fix now" items pulse on the drawing until opened?
